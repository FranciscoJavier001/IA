Ejercicio #2

El Número
Perdido

Ingresa una lista de números separados por coma.
El algoritmo encontrará el que falta.

Ejemplos rápidos:
Paso 1 — n —
→
Paso 2 — Suma esperada —
→
Paso 3 — Suma real —
Número perdido ?
script.js 
function numerosPerdido(arr) {
  const n = arr.length + 1;
  const sumaEsperada = (n * (n + 1)) / 2;
  let sumaReal = 0;
  for (let num of arr) {
    sumaReal += num;
  }
  return sumaEsperada - sumaReal;
}
